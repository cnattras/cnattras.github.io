Setting up the printer in linux with cups

1.  Make sure you have cups and foomatic installed.  (Foomatic contains the necessary drivers.)
1a.  Go to http://hplip.sourceforge.net/downloads.html and install this.  This contains updated drivers for linux - the default ones are screwy.
2.  Go to http://localhost:631/ in a browser.  (Your computer needs to be connected to the net or try http://127.0.0.1:631/, which is probably your local address.)  Click on "Manage Printers."  Go to Add Printer.
3.  The following are your choices as you walk through the set up:
    -Name, description, and location are arbitrary.  Choose something logical, like "HP4600","HP printer", and "visitor's room."  You will have to type the name in when using the command cupsdoprint, so you probably want something without special characters (ie, no spaces,) logical, and short.
    -Device:  "AppSocket/HP JetDirect"
    -Device URI:  "socket://130.132.158.38:9100"
    -Make: "HP"
    -Model/Driver:"HP Color Laserjet 4600 v3010.107 Postscript(recommended) (en)" (Manufacturer's driver) or "HP Color Laserjet 4600 Foomatic/Postscript(recommended) (en)"
4.  Now you have your printer set up.  Select "Configure Printer."  Defaults are mostly ok, but:
    -under "extra", select "Print Color as Gray" as "off"
    -under general, 2-Sided Printing: "Long-Edge Binding"
     -under general, paper source: "Auto"
    -under options installed, select duplex unit
After you've configured this, cups will tell you if there are any conflicts.
5.  Print a test page and make sure everything is ok.  If not, come see me and ask me questions.
