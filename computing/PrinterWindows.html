Installing the Printer on Windows

(Questions/ comments to Christine)

Download this file and install it

Go to the Start Menu -> Settings -> Control Panel->Printer and Faxes
Click on "Add Printer"
Choose "Local Printer" (no this is not a typo) and make sure the "Automatically..." box is unchecked
Click next
    Creating a new port
    Click "Create New Port" and choose "Standard TCP/IP Port"
    Click next (here and anywhere where it's not explicitly stated but is logical)
    Printer Name or IP Address: 130.132.158.38
    Port Name: 130.132.158.38
    If asked, choose Device Type: Standard and Generic Network Card
    Click Finish
(You are now back at the "Add Printer" screen)
Choose "have disk", click browse, and choose the driver you downloaded

Duplex Printing
In the Printer Control Panel, right click and select "Properties"
Click "Configure"
Make sure Duplexing Unit is checked

When printing, click "Properties", then "Finishing Tab", then "Print Both Sides."
