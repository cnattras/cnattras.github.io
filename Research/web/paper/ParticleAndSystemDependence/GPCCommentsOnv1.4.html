Some comments on the paper.

1. Line 134: There is no mentioning about pion and proton identification.
Pion and proton identification is not necessary for the reconstruction of V0s.
2. Line 182: Here it is mentioned that no correction for identified trigger is due to the fact that reconstruction efficiency is a constant as a function of pT_{trig}. However in line 158 it is stated that due to normalization by trigger once could ignore it. It sounded like two different reasons for ignoring reconstruction efficiency for identified trigger. Maybe I am missing something?
In dihadron correlations there are two potential reasons one would need to correct for the trigger particle's reconstruction efficiency: 1.  if the signal measured is dependent on the exact number of trigger particles 2. if the reconstruction efficiency changes significantly across the bin.  For example if we were to use a per-event normalization instead of per-trigger, the pair yield would depend on how likely we are to reconstruct the trigger particle.  Since we divide by the number of trigger particles, the single track efficiency for the trigger cancels out.  To put it in equations
dNpair/dphi = [dNpair,raw/dphi] / [eff(assoc) eff(trig)]
1/Ntrig dNpair/dphi = 1/[Ntrig,raw/eff(trig)] [dNpair,raw/dphi] / [eff(assoc) eff(trig)] = 1/Ntrig,raw [dNpair,raw/dphi] / [eff(assoc)]
However, if eff(trig) changes significantly across the bin, then 1/Ntrig dNpair/dphi above is no longer an accurate average of the trigger particles in the bin.  For instance, let's say (for the sake of argument) the trigger bin is 0.5-1.0 GeV/c.  In this case the efficiency more than doubles from 0.5 GeV/c to 1.0 GeV/c.  Without any correction, the measurement would over count trigger particles near 1.0 GeV/c and under count trigger particles near 0.5 GeV/c.  To be more explicit in the equation above, what we want is
<1/Ntrig dNpair/dphi> = 1/[Ntrig,raw/<eff(trig,pT)>]    <[dNpair,raw/dphi] / [eff(assoc) eff(trig,pT)] >
If eff(trig,pT) changes significantly across the bin, we would need to take a weighted average of the correlations from different triggers.  We can only cancel out the trigger efficiency in this case because the trigger efficiency is constant.
