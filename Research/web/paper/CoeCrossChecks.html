Information for code cross checks

Code for this analysis is stored in \$CVSROOT/offline/paper/psn0614/.  Documentation is in that directory in README.txt and README.pdf - you are encouraged to look at the pdf version since this has diagrams showing the structure of the code.  Note that this code is nearly identical to the code for \$CVSROOT/offline/paper/psn0530/ used for the system and energy dependence paper.


The input root files for different stages are available on RCF.

An XML to create TTrees:
/star/u/nattrass/AziCorrVer2/AuAu62TTrees/strangeAuAu62MinBias.xml
(Not that you couldn't write such an xml, but if you wanted to submit some sample jobs, this does it.)

Most of my sample code is set up to do CuCu200, so some TTrees from CuCu200 are here:
/star/institutions/npiascr/nattrass/CuCu200/TTreesMinBiasP06ibEmc/
(The output of TTreeMaker)

==============================

The correlation files are here
(The output of CorrelationMaker in different modes)
~nattrass/AziCorrVer2/rootFiles
with the CuCu200 files having CuCu200 in the name.

Files which are not track merge corrected are here:
in rootFiles/correlations/nottrackmergecorrected/
(Output of macros/correlations/RunCorrelationMaker.C)

the files at small dphi and deta without the track merging correction applied are here
rootFiles/correlations/trackmerge/
(Output of macros/correlations/RunCorrelationMakerForTrackMerging.C)

and the event mixing files are here
rootFiles/correlations/eventmix/
(output of macros/correlations/RunCorrelationMakerForEventMixingCuCu200.C)

If my naming convention for files is not clear, let me know - of course anyone reproducing the analysis would have to reproduce these files and come up with their own naming convention.
