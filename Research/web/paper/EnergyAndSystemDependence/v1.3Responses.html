Lines 456-458 - We tried various methods to get b.  With sufficient statistics one can just fit a constant at large delta-eta.  With lower statistics this is sometimes a bit trickier, especially if the jet-like peak is a little wider.  We stuck with bin counting to determine the yield because the peak is not truly Gaussian so some of the error in the fit comes from the fact that the data are not exactly Gaussian.  We get b from the fit, which is actually roughly comparable to a fit only at large statistics, but we throw out the other information from the fit.

This is the exact plot used in applying the correction.  When thinking of ways we could explain the track merging correction, we thought directly showing this plot would be useful.  Since this plot is sitting in a file on a hard drive already and just needed to be made pretty, we stuck with the exact binning used in the analysis.  This binning was chosen to:
1.  Optimize CPU usage
2.  Allow accurate matching of the smaller, track merge corrected area to the larger area that doesn't need to be corrected.  We apply the track merging correction in a small area only but then we have to patch it in to the larger area.  We didn't really know exactly what the limits would be  (especially because we also looked at V0s, Xis, and Omegas & hopefully that paper will be out soon) so we took an area large enough we were sure it would contain the whole dip for all particles.
3.  Allow rebinning if necessary (the number of bins is an integer which is the product of 2's and 3's to give us several options for rebinning)

So basically the dimensions of the histogram was chosen for analysis reasons.  Adding it as a figure in the paper to explain what we did was an afterthought.  We could zoom in but it would look better with finer binning if we zoomed in and it is not trivial to get finer binning - it would take running over the data again and possibly writing different code to do that.  So before we'd do that we'd want a good physics reason.  (Zooming in without rebinning would be trivial.)

The binning as is does put the effect in context.  A similar figure from Marek and Leon was zoomed in with very fine binning, but then the effect seemed much larger than it is.  We are not creating a peak with the track merging correction and we want to make sure the plot makes that clear.

 We did not specifically do this exercise for this paper.  Joern used ZYA1 (fixing the background at 1) instead and we are consistent with his analysis.  The v2 error is much larger than the error due to the background.  We include the statistical error on the background at the minimum in the statistical error on the yield.  Other STAR papers have not included changing the bin by one in the systematic error, and PHENIX does not include this in their errors.

The answer changes but it is also usually within the statistical error due to the background normalization.  (I would want to go back and look at this again before I would say that it is always within statistical error, but I did try both using the minimum point and the average of three points around the minimum and they were consistent.)  For low statistics samples (ie, AuAu62) these have already have few enough bins that changing by one might move you closer to a signal region and then we'd know the background is wrong.

I absolutely agree we want to make it clear that ZYAM is a caveat.  It is also no bigger of a caveat in this paper than in any of the other papers published using ZYAM.  I am confident that the physics message is robust.  We are saying the ridge grows with system size.  You can see this in raw plots - it is huge in central Au+Au and in Cu+Cu one has to look at the deta projections to see it.  Even though the 2D fit method with the cos(dphi) has its issues, it also sees an increase in the ridge with system size.  This is also seen in Michael Daugherity's e-struct analysis of Au+Au 62 & 200 - a completely different analysis method with dramatically different assumptions.  So I think the growth of the ridge with system size is a robust conclusion.

We also see the ridge/jet ratio is roughly independent of energy, and we want to make clear this is true only within the assumptions of this analysis.  I think it is likely fairly robust since we're likely to be making a mistake in the same direction for all data sets - but it is still possible there are different errors in different data sets.

But the jet-like correlation is not sensitive to ZYAM.  We also don't want to under-sell the data, so as much as we want to make it clear that there are caveats, we also want to make it clear that the jet-like correlation is not sensitive to them.
