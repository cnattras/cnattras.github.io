GPC Meeting minutes 1 Dec. 2010

Extensive discussion of v2 errors in Cu+Cu
  • Discussed v2{2}, v2{4}, v2{FTPC} and v2{AA-pp}.
  • Currently v2{2} is not used for any data set because it has a large non-flow component.
  • The main issue is that the Cu+Cu errors are larger than the Au+Au errors (by %).  This is because there were fewer measurements in Cu+Cu, not because v2 is known better.  Currently the systematic errors are determined by comparing v2{FTPC} to v2{CuCu-pp}.
  • v2{4} in Cu+Cu, if it were available, would be the ideal lower limit, but the statistical errors are large.  It was never published.
  • Paul discussed the limitations of v2{AA-pp}.  It assumes that the non-flow component (what is measured as v2 in p+p) scales with npart whereas it may scale with (for instance) nbin instead.
  • Lijuan sent the link to the long paper on Cu+Cu v2.
  • Several suggestions were made for how we could deal with the errors:
    • Use the v2{4} anyways.  The Cu+Cu data in this paper are fairly robust and therefore even if the lower bound is effectively zero we can still draw our physics conclusions.
    • Use v2{AA-pp} for Au+Au to get an error band in Au+Au comparable to what it is in Cu+Cu and show both error bands
    • Use the v2{CuCu-pp} from figure 4 of the long paper on Cu+Cu v2 to calculate v2{CuCu-pp} assuming binary scaling instead.  This can be done by taking what is in the paper, calculating diff=v2{FTPC}-v2{CuCu-pp}, and using v2=v2{FTPC}-Nbin/Npart*diff as the lower bound on v2.  Since v2{CuCu-pp} is only available at 200 GeV, assume a similar percentage error in the 62 GeV.
  • The general consensus was to use the last method.  The PAs will work on this, but anticipate that it will take some time to actually implement.
