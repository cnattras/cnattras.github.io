StHighPtEvaluator
    This library contains functions which are useful for determining whether things (events, tracks, V0 tracks) are good.  Most functions in this library return booleans.  Generally they are written to take either the standard STAR class (ex, StMuEvent) or the local container class (TEvent).

GetDefaultV0Cut.h    GetDefaultV0Cut.cxx
float GetDefaultV0Cut(string/char* dataset, string/char* type, string/char* cut, int partID)
float GetDefaultXiCut(string/char* dataset, string/char* type, string/char* cut, int partID)
    These functions return the default cut for a given data set.  Currently there are three different types of cuts (Correlation, TTree, Spectra) which can be defined, although it would be really easy to define a new cut.

IsGoodEvent.h   IsGoodEvent.cxx
bool IsGoodEvent(const string/char*, StMuEvent */TEvent*)
    This function asks whether the event is good or not.  It currently calls IsGoodMultiplicity, IsGoodVertex, and IsGoodTrigger for every data set.  Data set dependent checks could be added.  In the future the vertex ranking cut for CuCu200 should be added to this function instead of being done in AnalysisMaker.

IsGoodTrack.h    IsGoodTrack.cxx
bool IsGoodTrack(const char*/string dataset, StMuTrack/TTrack *track, float ptmin, float ptmax, float eta, float dca, int nHitsFit);
    Checks to see if the track passes the cuts.  For the TTrack, the dca cut does nothing because that variable is not stored.  No data set dependent cuts as of yet.
bool IsGoodProton/Kaon/Electron/Pion(const string/char* dataset, TIdentifiedTrack *track, float ptmin = 0.0, float ptmax = 10.0, float eta = 1.0 , float dca = 1.0 , int nHitsFit =15);
    Currently just asks if the particle's dEdx is within 2 sigma of the appropriate band.  These will be tuned to pt dependent cuts but this hasn't been done yet.

IsGoodV0Mass.h   IsGoodV0Mass.cxx
bool IsGoodV0Mass(string/char *dataset, float pt, float mass, int type);
bool IsGoodXiMass(string/char *dataset, float pt, float mass, int type);
    Does a cut on the mass of the V0 or Xi to see if it's within 1 sigma of the mass peak.  These cuts need to be tuned for CuCu200.
