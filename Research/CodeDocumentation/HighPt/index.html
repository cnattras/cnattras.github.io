HighPt libraries
StHighPtEvaluator
    This library contains functions which determine whether tracks, events, and vertices are good.
StHighPtLoop
    This library contains Makers which will loop over tracks, either in a TTree or in a MuDst.
StHighPtTools
    This library contains useful (data set dependent) tools, such as a function to determine the centrality bin, a function which returns the efficiency, and a function to calculate delta phi between -pi and pi given two angles.
StHighPtTree
    This library contains the container classes used in the TTree (TEvent, TTrack, TV0Track, etc).
