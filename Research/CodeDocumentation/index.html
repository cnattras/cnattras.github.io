Code Documentation

There are two groups of software libraries I have for the purposes of analysis:

HighPt
    These libraries are more general for the purpose of making TTrees which contain the information needed for analysis.
AzimuthalCorrelations
    These are the libraries with the software I use for analysis.

    These libraries were written such that it is easy to run the same analysis code on many different data sets.  In order to be useful for a particular data set, the appropriate data set dependent functions need to be defined in the libraries.  Most of the functions and analysis code works in a data set dependent way by passing around a string which gives the data set (ie, "CuCu200").  Some functions do the same thing for each data set but the functions were still written to take a string for the data set in case in the future things need to be done in a data set dependent way.
    Additionally, the code was written so that one piece of code (AnalysisMaker) could run over either TTrees or MuDsts.  AnalysisMaker passes good tracks from good events to other pieces of code such that the event and track cuts don't have to be written into later pieces of code.
